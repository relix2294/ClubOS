# ClubOS — сдача проекта

Платформа управления компьютерным клубом: облако (Cloud API + Admin Web), сервер клуба (Edge Controller) и
агент на игровых ПК (Windows Agent). Документ — для приёмки и запуска в эксплуатацию: что сделано, как развернуть,
как принять, что осталось.

## 1. Состав

```
Admin Web ──BFF──▶ Cloud API ◀──HTTPS, исходящее── Edge Controller ◀──LAN, mTLS── Windows Agent ─pipe─▶ SessionHost (экран)
(Next.js 16)        (.NET 10, PostgreSQL 18)         (.NET 10, SQLite WAL,        (служба Windows)      (Player Shell)
                                                      работает без интернета)
```

| Где | Что | Как ставится |
|-----|-----|--------------|
| VPS (Linux) | Cloud API, PostgreSQL, Admin Web, Caddy (HTTPS, Let's Encrypt) | [vps-deploy.md](runbooks/vps-deploy.md) |
| Сервер клуба (Windows) | Edge Controller — служба `ClubOSEdge`, `edge-cli`, касса `/cash` | [edge-windows-install.md](runbooks/edge-windows-install.md) |
| Игровые ПК (Windows) | служба `ClubOSAgent` + SessionHost (обычные и бездисковые ПК) | [windows-agent-install.md](runbooks/windows-agent-install.md) |
| Рабочее место администратора | браузер → `https://<домен>` | — |

Пакеты для Windows самодостаточные (.NET ставить не нужно). Их скачивают в Admin Web → «Подключение».

| Модуль | Что умеет | Подробно |

| Player Shell | Экран клуба, остаток и стоимость сессии, итог, вход техника по PIN | D-003, D-016 |
| Касса и отчёты | Смены, оплаты наличными/картой/с баланса, возвраты, внесение/изъятие, расхождение, выручка по дням | D-017 |
| Клиенты | Карточка по телефону, баланс-аванс, пополнение, корректировка, блокировка | D-017 |

| Работа без интернета | Сессии, расчёт и касса `/cash` на сервере клуба; автосинхронизация после связи | D-023, [offline-cash.md](runbooks/offline-cash.md) |
| Персонал | Роли Owner/Admin/Operator, права по локациям, 2FA, аудит всех действий | STATUS §5a |
| Безопасность | Сертификат у каждого ПК и Edge, подпись каждого запроса, mTLS в LAN, CRL, автопродление и ротация ключей | [dev-ca.md](security/dev-ca.md) |

## 4. Запуск в эксплуатацию — по шагам

1. **VPS.** Развернуть по [vps-deploy.md](runbooks/vps-deploy.md): заполнить `infrastructure/vps/.env` (свои
   пароли и ключи), `docker compose up -d --build`.
   - Включить ежедневный `backup.sh` с копированием за пределы VPS (§5 runbook).
   - Бэкап обязательно включает том `devca` — ключ CA.
2. **Пароль владельца.** Пароль владельца уже был виден вне системы, поэтому его нужно сменить:
   `docker compose exec cloud-api dotnet ClubOS.CloudApi.dll admin reset-password <email>`.
   Затем войти и включить 2FA.
3. **Сотрудники и локация.** В Admin Web: локация, зоны и цены, сотрудники с ролями. Кассирам задать PIN офлайн-кассы
   («Мой пароль»).
4. **Сервер клуба.** Admin Web → «Подключение» → токен Edge, затем пакет Edge, затем `INSTALL.cmd`. Порядок обновления
   всегда такой: сначала Edge, потом Cloud.
5. **Игровые ПК.** Токен ПК и отпечаток CA из «Подключение», затем пакет агента, затем `INSTALL.cmd`. Бездисковые ПК
   подтверждаются в «Устройства».
6. **Закрыть переходные режимы**, когда все ПК клуба на текущей версии:
   `install-edge.ps1 … -DisableAgentHttp -RequireClientCertificate`. После этого HTTP 7070 закрыт, а ПК без
   сертификата отклоняются.
7. **Приёмка** по чек-листу [acceptance-test.md](runbooks/acceptance-test.md), разделы A–Q. Протокол ручного теста
   на Windows записать в [STATUS.md §4](STATUS.md).

Обновление версии: `git pull`, затем `CLUBOS_VERSION=$(git rev-parse --short HEAD) docker compose up -d --build`
(для демо-зала добавить `--profile demo`).

## 5. Что не входит в сдачу и почему

| Пункт | Почему | Что нужно для продолжения |
|-------|--------|---------------------------|
| Фискальные чеки (ККТ) | Нет спецификации протокола/модели ККТ Таджикистана | Модель кассы, протокол, требования налоговой |
| Несколько Edge на одну локацию | Отложено: один Edge на клуб покрывает пилот | Решение по распределению ПК между Edge |
| Ключ CA в HSM/KMS | Ключ — файл с правами 600 в отдельном томе; для пилота достаточно | Выбор KMS (облако VPS или аппаратный) |
| Ручной тест на реальном Windows | Среда разработки без Windows; CI собирает и запускает Edge и агента на Windows | Пройти разделы I и Q чек-листа в клубе |

Все упрощения относительно ТЗ с обоснованием и статусом — в [DEVIATIONS.md](DEVIATIONS.md).
