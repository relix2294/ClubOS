# Боевой тест ClubOS M1: чек-лист тестировщика

Проверяем всё, что есть в M1, на развёрнутом VPS ([vps-deploy.md](vps-deploy.md)) с включённым демо-залом (п. 3a)
и, по возможности, на настоящих Windows ПК. Отмечайте в колонке «✓/✗» результат. Для каждого ✗ заполните
отчёт по шаблону в конце: без шагов и скриншота ошибку трудно повторить.

## 0. Что нужно

| Что | Где взять |
|-----|-----------|
| Адрес Admin Web | `https://<домен VPS>` |
| Логин и пароль владельца | у владельца лично (не пересылать в открытых чатах) |
| Телефон с приложением-аутентификатором | Google Authenticator, Microsoft Authenticator или Aegis |
| Два браузера (или обычное окно и инкогнито) | для проверки live-обновлений и второго сотрудника |
| Для части I: сервер клуба и игровой ПК на Windows 10/11, права администратора | пакеты из GitHub Actions: `clubos-edge-windows`, `clubos-windows-agent-selfcontained` |

Время на экранах и в отчётах — по часовому поясу локации (Asia/Dushanbe). Суммы — в TJS.

## I. Настоящий клуб на Windows

По runbook'ам: [edge-windows-install.md](edge-windows-install.md) и [windows-agent-install.md](windows-agent-install.md)
(пункты 1–25). Кратко:

| № | Шаг | Ожидаемо | ✓/✗ |
|---|-----|----------|-----|
| I1 | Токен Edge для основной локации → `install-edge.ps1 -CloudUrl https://<домен>` | На дашборде основной локации «Edge на связи» | |
| I2 | «Подключение» → «Отпечаток CA» → скопировать команду агента, подставить IP сервера | `install-agent.ps1 -EdgeUrl https://<IP>:7443 -EdgeCaFingerprint … -EnrollmentToken …` завершился без ошибок | |
| I3 | ПК в Admin Web | «Свободен», инвентаризация (имя, Windows, CPU, RAM, IP) | |
| I4 | Неверный отпечаток при установке на другом ПК | Агент не подключается, причина в Event Log | |
| I5 | `-ShellMode Enforced -TechnicianPin …` | Свободный ПК закрыт экраном клуба; Win/Alt+Tab не работают; Ctrl+Alt+Del работает | |
| I6 | Сессия из Admin Web с лимитом | Экран открывается, индикатор остатка и стоимости | |
| I7 | Ctrl+Shift+F12 и PIN | Режим обслуживания на 15 мин, в Admin Web «Обслуживание» | |
| I8 | Отключить интернет у сервера клуба (LAN оставить) | Сессия идёт, лимит завершает её сам; после возврата интернета итог в Cloud | |
| I9 | «Удалить устройство» в карточке ПК | ПК пропал; агент получает отказ; вернуть — новым токеном с `-ReEnroll` | |
