# Боевой тест ClubOS M1: чек-лист тестировщика

Проверяем всё, что есть в M1, на развёрнутом VPS ([vps-deploy.md](vps-deploy.md)) с включённым демо-залом (п. 3a)
и, по возможности, на настоящих Windows ПК. Отмечайте в колонке «✓/✗» результат. Для каждого ✗ заполните
отчёт по шаблону в конце: без шагов и скриншота ошибку трудно повторить.

## 0. Что нужно

| Что | Где взять |
|-----|-----------|
| Адрес Admin Web | `https://<домен VPS>` |
| Логин и пароль владельца | у владельца лично (не пересылать в открытых чатах) |
| Телефон с приложением-аутентификатором | Google Authenticator, Microsoft Authenticator или Aegis |
| Два браузера (или обычное окно и инкогнито) | для проверки live-обновлений и второго сотрудника |
| Для части I: сервер клуба и игровой ПК на Windows 10/11, права администратора | Admin Web → «Подключение» → «Скачать Edge» и «Скачать агент» (или `https://<домен>/downloads/`) |

Время на экранах и в отчётах — по часовому поясу локации (Asia/Dushanbe). Суммы — в TJS.
