# Касса клуба без интернета (Edge)

Когда у клуба пропадает интернет, Admin Web (на VPS) недоступен, но сервер клуба (Edge) продолжает считать
сессии. Касса Edge позволяет принимать **оплату сессий наличными и картой** прямо в сети клуба. Оплаты хранятся
на сервере клуба и уходят в облако сами, когда связь вернётся (D-023).

## Подготовка (пока интернет есть)

1. Каждый кассир, который должен работать без интернета: Admin Web → «Мой пароль» → «PIN кассы клуба без
   интернета» → 6–8 цифр + текущий пароль → «Задать PIN». PIN нельзя `123456`, `111111` и подобные.
2. Сервер клуба получает список кассиров с PIN в течение минуты (сразу — командой обновления конфигурации).
   Кассир видит себя в списке на странице кассы Edge.
3. На компьютере кассира в клубе добавьте закладку **`https://<адрес сервера клуба>:7443/cash`** (тот же адрес,
   что у агентов ПК). Браузер предупредит о сертификате: он выпущен CA ClubOS, а не публичным центром. Либо
   установите CA (Admin Web → «Подключение» → отпечаток CA), либо откройте `http://<адрес>:7070/cash`, если
   HTTP для агентов ещё включён.

## Когда интернета нет

1. Откройте закладку кассы Edge, выберите себя, введите PIN. Пять неверных PIN подряд — вход заблокирован на 5 минут.
2. «К оплате» — сессии с долгом за последние 48 часов: завершённые и идущие с лимитом (предоплата).
   Долг = начислено по данным сервера клуба − оплачено в облаке (последнее, что облако успело сообщить) − принято
   на этой кассе.
3. Введите сумму (не больше долга) и нажмите «Наличные» или «Карта». Двойное нажатие не создаёт вторую оплату.
4. «Принято на этой кассе» — оплаты Edge с отметкой «ждёт отправки» / «в облаке». Жёлтая плашка вверху — есть
   события, которые ещё не ушли в облако.

## Когда интернет вернулся

- Оплаты уходят в облако автоматически и проводятся в **открытую кассовую смену** локации от имени кассира,
  принявшего деньги. Если смена закрыта — облако **открывает её само** (наличные на начало 0); пересчитайте кассу
  и закройте смену как обычно.
- В «Касса» → «Операции смены» у таких оплат основание «Касса Edge без интернета, <время>».
- Если в облаке за это время кто-то принял оплату той же сессии, у сессии будет переплата — её видно в
  «К расчёту», вернуть её можно как обычно.

## Что касса Edge не делает

Возвраты, пополнение и списание балансов клиентов, бар, открытие и закрытие смены — только в Admin Web.
Удалить PIN: «Мой пароль» → «Удалить PIN» (кассир пропадает с сервера клуба в течение минуты; вход по cookie
перестаёт действовать сразу после обновления конфигурации).
